# 🐛 Reporting issues

[Public documentation](README.md)

Search the [Issues tab](https://github.com/CoC-MS/ALSO-Microsoft-Security-Conditional-Access/issues) before reporting a problem. Use the repository's [issue chooser](https://github.com/CoC-MS/ALSO-Microsoft-Security-Conditional-Access/issues/new/choose): bug report, documentation/licensing correction, or feature/policy request.

Include the exact package, policy number and filename, relevant licence/feature availability, import tool version, selected workloads/state, reproduction steps, and expected versus actual behavior. For documentation feedback, identify `README.md` or the precise page under `docs/public`.

> [!IMPORTANT]
> Public issues are visible to everyone. Do not attach tenant exports, credentials, tokens, certificates or private keys, customer details, tenant/user/device IDs, group memberships, assignments, or unredacted logs and screenshots. Provide a minimal redacted example instead.

Read [Security information](../../Security.md) for implementation responsibilities. Do not disclose exploitable vulnerabilities or sensitive security details in a public issue. Use GitHub private vulnerability reporting if available, or an established private disclosure channel.
